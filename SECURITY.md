# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| Latest GitHub Release / `main` | Yes |
| Older releases | Best-effort |

## Reporting a vulnerability

Please report security issues **privately** — do not open a public GitHub issue.

Use [GitHub private vulnerability reporting](https://github.com/danielnachumdev/gp_wrapper/security/advisories/new).

Include a clear description, steps to reproduce, and impact assessment if known.

## Disclosure

- We aim to acknowledge reports promptly.
- We will work with you on a fix and coordinate public disclosure.
- Please allow reasonable time for a patch before public disclosure.

We appreciate responsible disclosure and will credit reporters when appropriate.
